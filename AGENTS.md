# CHLOM Core Agent Contract — Phase 3 Execute

## Mission
Build CHLOM as CrownThrive's governed rights and institutional operating system for Rights, Rules, Roles, Revenue, Records, and Remedies.

CHLOM itself is the protocol/control-plane/ledger system. LEX is one consuming application. Do not treat a LEX workspace release as completion of the core. The September 20 founder scope clarification governs future implementation and release reports; preserve earlier component evidence as history.

## Current architecture
- Cloud-first, API-first, event-driven, multi-tenant, human-governed.
- DAIL = Decentralized Autonomous Information Ledger.
- DLA = Dynamic Licensing Asset.
- Historical Decentralized Licensing Authority responsibilities are now Licensing Stewardship / Issuer Authority.
- Blockchain, tokens, DAO governance, ZK orchestration, bridges, validators and public cryptographic settlement are gated target architecture, not current-state claims.

## Public repository restrictions
Never commit credentials, raw evidence, private financial/customer records, unreleased assets, privileged communications, proprietary Fingerprint implementation, private policy DSL, confidential economic calibration, partner pricing, or restricted source documents.

## Non-negotiable operating rules
- Evidence is private by default.
- Corrections append; never silently overwrite history.
- A public page, token, hash, NFT, checkout or automated decision is not proof of legal ownership by itself.
- Human approval is required for rights grants, enforcement, legal/compliance determinations, live economics, destructive changes and protected-data disclosure.
- Historical terminology conflicts must be resolved in ADRs rather than guessed.
- Do not claim a module is active without production evidence.
