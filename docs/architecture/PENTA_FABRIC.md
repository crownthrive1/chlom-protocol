## Maintenance contract

PentaSpecter is scheduled for a strict daily 2:00 AM through 5:00 AM America/New_York maintenance window. The runtime uses local-time gating around DST-safe UTC cron candidates. It creates no new Penta maintenance work after the 5:00 AM deadline. Unfinished Penta work is held or expired according to state instead of silently running as a new maintenance cycle.

The maintenance workflow is expected to:

1. inspect actual recent failure evidence;
2. create reproducible, bounded fix requests;
3. hand valid requests to the CrownThrive Autonomous Software Factory;
4. require security, test, packaging, deploy, assurance, and rollback lanes;
5. package ordinary bug fixes as patch candidates;
6. package every active security finding separately;
7. classify critical security fixes as hotfix candidates with a security appendix policy;
8. preserve major-version decisions as governed candidates rather than inferring a major release automatically.
