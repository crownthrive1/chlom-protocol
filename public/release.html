Private by design

A record you can
verify later.

These tools run on your device. The file is not uploaded. A commitment establishes byte consistency when opened; it does not prove authorship, rights, or legal compliance.

Keep the private opening confidential. Anyone with the opening can test candidate files against it. This is a salted SHA-256 commitment, not a zero-knowledge proof.

Maximum 25 MB. File names are excluded from the commitment.
