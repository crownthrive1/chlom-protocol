# Third-party SPDX text catalog

These license and exception texts are unmodified files from the official
[SPDX license-list-data](https://github.com/spdx/license-list-data) repository,
tag `v3.26.0`, commit `8a04f0303d95c4f932210b118588c662665bd383`.
`manifest.json` records the exact upstream URL and SHA-256 hash of each file.
The packaging script verifies those hashes before copying any catalog text.

These texts describe third-party terms and are not CrownThrive-authored code.
They do not relicense their referenced packages or the surrounding repository.
The dependency inventory preserves each crate's declared license expression,
package authors, source revision and any original license/notice files. Some
published crates omit standalone license files; the inventory makes that absence
explicit and supplies the declared standard terms from this catalog. Full
corresponding source preserves the original source-level notices.
